# iA Writer Templates

Custom templates for [iA Writer](https://ia.net/writer).

## Lit Mag Submission

A clean manuscript template for anonymous literary-magazine submissions. It provides:

- A bold, centered title with one blank line below it
- Indented, double-spaced body text
- Page numbers in the upper-right header without an author name
- Centered `* * *` scene breaks when Markdown horizontal rules such as `----` are used

This template is based on the public [MLA Style iA Writer template](https://github.com/plutonium-239/deeprl-in-sgbd/tree/master/paper/mla/MLA%20Style.iatemplate), which is also included in this repository as `MLA Style.iatemplate`.

## Writing paragraphs and scene breaks

For a forced new line while writing a scene, press **Shift–Enter**. iA Writer inserts the Markdown backslash (`\`) hard-break marker. Use `----` on its own line when you want a visible scene divider; **Lit Mag Submission** renders it as centered `* * *`.

## Install

1. Double-click the `.iatemplate` bundle you want to install.
2. For **Lit Mag Submission**, enable **Headers** and disable **Footers** in iA Writer's template settings.
3. Select the installed template when previewing or exporting a document.
